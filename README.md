# Esfera Mapa Normal

Proyecto realizado en Unity para la creación de una esfera 3D con un mapa normal personalizado, una luz y un material de color rojo.

## Desarrollo
1. Crear esfera
2. Agregar mapa normal a la esfera
3. Agregar Point Light
4. Cambiar color de la esfera a rojo

## Versión
Unity 6000.6.7f1
